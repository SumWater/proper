\begin{abstract}
Historical failure memories can change a tool-using language-model agent's recovery decision, but retrieval similarity does not establish that a memory is applicable to the current failure. We study \proper, a conservative selector that uses only observable execution evidence to rank candidate memories and replaces the TF-IDF Rank-1 candidate only when an alternative is supported and decisively preferable. Across two instruction-tuned models, three failure strata, and a frozen 403-target changed-selection population, \proper{} improves paired Recovery Validity over TF-IDF by 3.72 percentage points for Qwen3-8B and 5.46 points for Mistral-7B-Instruct-v0.3. It also outperforms frozen Dense and LLM-Judge baselines in both models. These relative gains do not imply that memory is universally useful: all evaluated memory methods remain below No Memory overall for Mistral, and timeout or authorization strata contain zero or weak effects. Ablations identify the conservative gate as the clearest supported component, while contradiction checking has no stable independent behavioral benefit. Our conclusions are limited to the evaluated benchmark, memory bank, models, and one-step recovery horizon.
\end{abstract}
