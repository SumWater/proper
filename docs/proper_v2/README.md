# PROPER v2 documentation

This directory will contain the unified PROPER v2 method specification,
preregistrations, preparation reports, and result reports. Historical PROPER
v1 documents are preserved in `../proper_v1/`.

- `unified_proper_v2_design.md`: unified observable-state, policy-card, and
  conservative-selection specification.
- `toolsandbox_model_pilot_v2_1_protocol.md`: frozen phase-aware external
  stateful-agent pilot design and interpretation boundary.
- `toolsandbox_qwen_pilot_v2_1_results.md`: frozen exploratory Qwen3-8B
  results, phase interaction, failure analysis, and v2.2 design consequence.
- `memory_lifecycle_v2_2_protocol.md`: frozen unified lifecycle development
  contract.
- `toolsandbox_qwen_lifecycle_development_v2_2_results.md`: development-only
  Qwen3-8B lifecycle results, with selector, lifecycle, completion, safety,
  and cost reported separately.
- `memory_continuation_v2_2_1_protocol.md`: versioned consumed-action replan
  contract created after the frozen v2.2 outputs.
- `toolsandbox_continuation_target_inventory_v2_2_1_protocol.md`: prospective
  no-play inventory gate for acquiring new continuation targets.
- `continuation_development_v2_2_1_stage.md`: local readiness, remote guard
  sequence, expected outputs, and interpretation boundary.
- `toolsandbox_qwen_continuation_development_v2_2_1_results.md`:
  development-only four-condition results separating selector, lifecycle,
  continuation, completion, safety, cost, and target-capacity conclusions.
- `freeze_commit_plan.md`: exact three-commit evidence separation; no staging
  or commit is performed by the document.
