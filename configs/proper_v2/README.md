# PROPER v2 configurations

This directory is reserved for PROPER v2 development, capacity-audit, and
confirmatory configuration files. PROPER v1 configurations are preserved in
`../proper_v1/`.

The `memory_continuation_v2_2_1.yaml` family is a versioned development
extension created after the frozen v2.2 outputs. It must not be substituted
for the earlier frozen lifecycle configuration.
