This directory is reserved for new execution-aware lifecycle development.
Configurations under `configs/proper_v2/` are frozen ancestry and must not be
modified or copied here without an explicit source path and SHA-256.

No GPU or confirmatory run is currently authorized.

  repeat, unknown-outcome, and observable-input policy.
