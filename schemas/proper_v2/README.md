# PROPER v2 schemas

This directory is reserved for PROPER v2 observation, memory-policy,
selection-decision, capacity-audit, and result schemas. PROPER v1 schemas are
preserved in `../proper_v1/`.

- `observable_failure.schema.json`
- `observable_recovery_state.schema.json` (v2.1 pre-action/post-failure)
- `memory_policy_card.schema.json`
- `selection_decision.schema.json`
- `selection_decision_v2_1.schema.json`
- `memory_lifecycle_v2_2.schema.json`
- `memory_continuation_v2_2_1.schema.json`
